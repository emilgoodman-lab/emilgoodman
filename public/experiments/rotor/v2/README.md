# Rotor II — Painted Resonator

A preserved new edition of Rotor: 28 concentric rings built from 28 permanent motifs, interleaved across all four user-provided painted references. Rough geometric clipping retains the source paint; transparent sprites cache strong compact drop shadows and overlap along the actual projected ring tangent. Black is the calm background. No debug UI or visible sliders; the raised webcam card is the only control.

The original four field weights and spatial overlap remain: upper field creates a darkening depth tunnel, right gives delayed XY drift, lower turns individual pieces sequentially, left tilts the planes, center blends all four. Scroll or K cycles the original 0–16-sector kaleidoscope. Holding a pointer or a tracked fist inverts the canvas and smoothly raises phase speed, oscillation speed and displacement/tilt amplitude on all rings. Opening, releasing, cancellation, tracking loss and leaving the tab restore the calm state. The integrated motion clock avoids angle discontinuities.

The audio reuses Talisman's original Turkish-inspired physical plucked-string and breath-flute material and modulates resonant filtering, pitch, tremolo, stereo movement and room response from the visual field weights. Held interaction adds instrument distortion and rapid ornamentation. This is procedural original music rather than a historical recording. First pointer press or webcam-button gesture starts audio; M mutes. P pauses and reduced-motion preference starts paused without inversion. Webcam tracking stays local and never requests microphone access.

Rendering caches images, cutouts and shadows; only visible pieces are painted in normal mode, while the shared offscreen field supports kaleidoscope compositing. The first pink source is shared with Abyssal v2; the other three references total approximately 745 KB.

Checks: original Rotor and catalog tests, four new model tests for field equivalence, permanent unique motifs, reliable held-state release, amplified finite projections; browser pointer/touch/hand synthetic input, cursor states, all four center weights, kaleidoscope, pause/resume, audio activation, mobile layout and reduced motion. Four actual audio graphs render finite stereo output without clipping. Physical webcam hardware is not exercised by these synthetic checks.
